### What is this project? 
This is a keyboard made from scratch made by a teenage, made from PCB, CAD to firmware everything! basically this is a keyboard which helps you type things and uses RP2040 and and it sounds thockyy!! 

### How to use it?
1. Assemble the PCB by soldering the Raspberry pi pico, switches and encoder and the OLED display which is on the numpad pcb
2. Plug the MCU (raspberry pi pico) with your computer and make sure the boot button on the MCU is pressed down while you are plugging in the MCU
3. Drag and drop the .uf2 file in the MCU of Raspberry Pi Pico 
4. Do the same things with Xiao rp2040
5. wolla you have everything working!! 

### Why did i made this? 
I made this to learn new skills and learn more about PCBs and do ALOT of CAD the case/CAD of this project took so much time! and the case makes it looks so much awesome! and i have made a separate numpad which can alsop be used as a macropad, you can use it as a full sized keyboard or just as a ANSI-75 Keyboard with a small macropad on your desk! the numpad also have a keychian holder so you can carry it easily too! 

# Features
- EC11 Rotary Encoder - For Volume, Brightness etc
- Oled screen -  To play gifs and notifications
- ANSI-75 Layout
- Raspberry Pi Pico
- Custom Layout
- QMK firmware
- Awesome CAD/cool case design
- Uses RP2040
